# Roadmap

This roadmap describes the work needed to move QuizMaster from a functional local game-night application to a dependable public release.

## v0.1 — Public foundation

- Publish a clean public repository with documentation, a license, contribution guidance, issue templates, and CI.
- Keep local development and single-host sharing reproducible.
- Establish feature-first backend and frontend organization.

## v0.2 — Reliable game night

- Complete manual smoke coverage for all three game modes.
- Polish host moderation flows, score correction, camera presentation, and actionable feedback.
- Improve content management with safe reuse, clear history, and duplicate avoidance.

## v0.3 — Production-ready sharing

- Document trusted private and temporary public sharing paths.
- Add structured operational checks and clearer configuration examples.
- Strengthen error handling and observability for OAuth, cameras, and realtime reconnects.

## v1.0 — Stable community release

- Resolve the release-readiness issues in GitHub.
- Complete a multi-device game-night test.
- Publish a tagged release with migration and upgrade notes.
